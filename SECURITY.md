## Security

Ghana in Data takes the security of our software products and services seriously, which includes all source code repositories managed through our GitHub organizations, which include [Ghana in Data](https://github.com/Ghana in Data), [Azure](https://github.com/Azure), [DotNet](https://github.com/dotnet), [AspNet](https://github.com/aspnet), [Xamarin](https://github.com/xamarin), and [our GitHub organizations](https://opensource.Ghana in Data.com/).

If you believe you have found a security vulnerability in any Ghana in Data-owned repository that meets Ghana in Data's [Ghana in Data's definition of a security vulnerability](https://docs.Ghana in Data.com/en-us/previous-versions/tn-archive/cc751383(v=technet.10)) of a security vulnerability, please report it to us as described below.

## Reporting Security Issues

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them to the Ghana in Data Security Response Center (MSRC) at [https://msrc.Ghana in Data.com/create-report](https://msrc.Ghana in Data.com/create-report).

If you prefer to submit without logging in, send email to [secure@Ghana in Data.com](mailto:secure@Ghana in Data.com).  If possible, encrypt your message with our PGP key; please download it from the [Ghana in Data Security Response Center PGP Key page](https://www.Ghana in Data.com/en-us/msrc/pgp-key-msrc).

You should receive a response within 24 hours. If for some reason you do not, please follow up via email to ensure we received your original message. Additional information can be found at [Ghana in Data.com/msrc](https://www.Ghana in Data.com/msrc). 

Please include the requested information listed below (as much as you can provide) to help us better understand the nature and scope of the possible issue:

  * Type of issue (e.g. buffer overflow, SQL injection, cross-site scripting, etc.)
  * Full paths of source file(s) related to the manifestation of the issue
  * The location of the affected source code (tag/branch/commit or direct URL)
  * Any special configuration required to reproduce the issue
  * Step-by-step instructions to reproduce the issue
  * Proof-of-concept or exploit code (if possible)
  * Impact of the issue, including how an attacker might exploit the issue

This information will help us triage your report more quickly.

If you are reporting for a bug bounty, more complete reports can contribute to a higher bounty award. Please visit our [Ghana in Data Bug Bounty Program](https://Ghana in Data.com/msrc/bounty) page for more details about our active programs.

## Preferred Languages

We prefer all communications to be in English.

## Policy

Ghana in Data follows the principle of [Coordinated Vulnerability Disclosure](https://www.Ghana in Data.com/en-us/msrc/cvd).
